Database applications store and serve application data. Choose an application based on your data
model, query requirements, and operational needs.

## Available applications

- [MongoDB 8.0](/public-cloud/marketplace/mongodb)
- [MariaDB 11.8](/public-cloud/marketplace/mariadb)
- [MySQL](/public-cloud/marketplace/mysql)
- [PostgreSQL](/public-cloud/marketplace/postgresql)
- [Valkey 9.1](/public-cloud/marketplace/valkey)
- [Elasticsearch 9](/public-cloud/marketplace/elasticsearch)
- [InfluxDB 2](/public-cloud/marketplace/influxdb)

Review each application page for included software, configuration, and access instructions before
deployment.
