## Change VM Plan

This option lets you upgrade your VM's resource allocation, such as CPU cores and RAM. The plan
change process requires a reboot of the VM.

- To change your plan, go to the **VM Settings** and navigate to the **Change Plan** section.
- Select from the available fixed plans. Custom plans are retired.
- A plan change affects CPU and memory only. It does not change the root disk. Grow the root disk at
  any time. It never shrinks.

:::caution

Downgrading is currently not supported. Shrinking the hard disk is not possible without risking data
loss.

:::

- Review the details and click **Review and Change Plan** to apply the new plan.
