title: Compute
description: Deploy and manage virtual machines in ZCP.

Compute provides virtual machines for applications, development environments, and workloads that
need dedicated resources. Create an instance, select its plan and operating system image, then
connect through SSH, RDP, or the console.

## Choose Your Instance

When you create an instance, select:

- A region and project for the workload
- A plan with the CPU, memory, and storage that it needs
- An operating system image or a Marketplace application image
- A network and access method

See [Create Instance](/public-cloud/compute/create-instance) for the full portal workflow. See
[Instance Types](/public-cloud/compute/instance-types) to compare plans.

## Operate Your Instance

After deployment, use the instance page to view its status, resource usage, network addresses, and
available actions. You can start, stop, reboot, resize, change settings, and review activity from
the portal.

Use [Instance Overview](/public-cloud/compute/instance-overview) for the available controls.
