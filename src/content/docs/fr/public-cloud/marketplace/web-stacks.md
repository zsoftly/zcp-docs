Les applications de piles Web fournissent un point de départ pour héberger des sites Web et des
applications Web. Choisissez une pile adaptée au framework de votre application et à vos besoins en
bases de données.

## Applications disponibles

- [WordPress](/fr/public-cloud/marketplace/wordpress)
- [Pile LAMP](/fr/public-cloud/marketplace/lamp)
- [Pile LEMP](/fr/public-cloud/marketplace/lemp)

Consultez la page de chaque application pour connaître les logiciels inclus, la configuration et les
instructions d'accès avant le déploiement.
