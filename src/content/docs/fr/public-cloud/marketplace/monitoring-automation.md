Les applications de surveillance et d’automatisation vous aident à observer vos services et à
automatiser les tâches courantes. Choisissez une application selon les systèmes à surveiller ou les
flux de travail à automatiser.

## Applications disponibles

- [Grafana](/fr/public-cloud/marketplace/grafana)
- [n8n](/fr/public-cloud/marketplace/n8n)

Consultez la page de chaque application pour connaître les logiciels inclus, la configuration et les
instructions d'accès avant le déploiement.
