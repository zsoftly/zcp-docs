Les applications d’outils de développement prennent en charge le développement local, la livraison
des applications et les tâches opérationnelles. Choisissez une application selon le runtime, les
outils de conteneurs ou le service dont vous avez besoin.

## Applications disponibles

- [Docker](/fr/public-cloud/marketplace/docker)
- [Node.js 24](/fr/public-cloud/marketplace/nodejs)
- [OpenClaw](/fr/public-cloud/marketplace/openclaw)

Consultez la page de chaque application pour connaître les logiciels inclus, la configuration et les
instructions d'accès avant le déploiement.
