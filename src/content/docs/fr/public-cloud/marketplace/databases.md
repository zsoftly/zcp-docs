title: Applications de bases de données

Les applications de bases de données stockent et servent les données de vos applications. Choisissez
une application selon votre modèle de données, vos besoins en requêtes et vos besoins opérationnels.

## Applications disponibles

- [MongoDB 8.0](/fr/public-cloud/marketplace/mongodb)
- [MariaDB 11.8](/fr/public-cloud/marketplace/mariadb)
- [MySQL](/fr/public-cloud/marketplace/mysql)
- [PostgreSQL](/fr/public-cloud/marketplace/postgresql)
- [Valkey 9.1](/fr/public-cloud/marketplace/valkey)
- [Elasticsearch 9](/fr/public-cloud/marketplace/elasticsearch)
- [InfluxDB 2](/fr/public-cloud/marketplace/influxdb)

Consultez la page de chaque application pour connaître les logiciels inclus, la configuration et les
instructions d'accès avant le déploiement.
